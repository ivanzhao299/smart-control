# 云端 MAX 节点准备单（未开通）

> 已停用的旧备选：用户明确要求不购买云主机、不配置另一台电脑。当前使用 Mac 本地开源 MAX 解析工作流，见 README。下文不代表执行计划或开通授权。

目标是按需处理资产并取回轻量模型，避免生产大屏电脑承担建模和烘焙负担。

## 推荐落地顺序

1. 使用已有云账号开通一台 Windows x64 图形工作站。创建前确认 Windows 镜像与 Max 版本兼容，以及 Max/V-Ray 许可允许该运行方式。
2. 初始参考配置：16 vCPU、32 GB 内存、8 GB 显存；磁盘按安装空间选型。按小时计费，不默认包年，不设置自动续费。
3. 从官方账户安装并激活兼容的 Max 与 V-Ray；先运行 `windows-export.ps1 -InspectOnly`，然后用小场景实际验证。检查文件存在不能证明许可证或插件能工作。
4. 将本地 `worker-package.zip` 上传到指定节点。确认没有缺失插件、素材和阻塞弹窗后处理完整园区。
5. 导出并取回 `max-export`，在 Mac 上运行 `twin.py convert`、浏览器验收，再决定是否替换生产网页。
6. 验证结果和原文件备份后关闭计算实例。关机不等于停止所有费用，磁盘/快照费用要单独核对。删除云磁盘前须确认输出已取回。
