## 1. 本批目标

`HvacPage.vue` 原来直接维护空调目录加载、真机状态轮询、写后冷却和 keep-alive 定时链。一个轮询若在设备命令之前启动、命令之后才返回，会用旧寄存器快照覆盖刚完成的乐观状态；原定 1.2 秒后的真机复读又会命中 2.5 秒常规冷却而直接跳过。页面停用或身份切换期间的在途请求还可能提交旧服务器数据，或在返回后重新排出孤儿轮询。

本批把目录加载、状态合并、写入失效、强制复读、身份变化和页面激活生命周期统一提取到 `useHvacRuntimeState.ts`。每次读取绑定身份、读取修订、写入修订和激活周期，旧响应不能再进入当前页面。

## 2. 收敛后的责任边界

组合式用例统一负责：

- 并行读取内机与分区目录，保留已有真机状态并清理已经不存在的选择；
- 以单条递归定时链读取真机状态，后台、命令执行中和常规写后冷却期不请求网关；
- 设备命令开始时递增写入修订，立即作废此前启动的状态读取；
- 命令完成后单独安排强制真机复读，只绕过常规冷却，不绕过页面、身份或忙碌边界；
- 页面停用时取消常规轮询与写后复读，并阻止在途请求恢复定时链；
- 账户或服务器身份变化时重新加载权威目录，抑制旧服务器成功、失败和状态提交；
- 页面作用域销毁时注销身份监听并清理全部计时器。

`HvacPage.vue` 从 1544 行降至 1466 行。模板、样式、5 秒轮询间隔、1.2 秒写后复读、2.5 秒常规冷却、API 和设备命令路径保持不变。

## 3. 防回归契约

新增 6 项可执行测试，覆盖：

1. 目录刷新保留已知状态并清理已不存在的选择；
2. 命令前启动的旧轮询不能覆盖乐观状态；
3. 写后真机复读能够绕过常规冷却并实际读取；
4. 页面停用抑制在途轮询并阻断孤儿定时链；
5. 身份切换重新加载目录且旧服务器结果不能提交；
6. 结构门禁禁止目录、状态服务和轮询编排回流页面组件。
