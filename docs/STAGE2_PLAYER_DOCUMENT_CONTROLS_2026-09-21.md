## 1. 本批目标

`PlayerConsole.vue` 在欢迎页、输入源和播放列表旅程拆分后，仍直接处理文档翻页、缩放和退出放映。翻页或缩放请求发出后，如果操作员切换屏幕、换片、重新登录或离开页面，旧响应仍会写入共享播放状态，可能造成页码倒退、缩放回跳或控制错会话。

本批把完整文档放映控制提取到 `usePlayerDocumentControls.ts`，使每次异步操作同时绑定发起时的屏幕、播放会话、身份和请求版本。任何边界变化都会立即废弃旧请求的可见结果，同时允许新会话继续操作。

## 2. 收敛后的责任边界

组合式用例统一负责：

- 从权威播放通道投影文档播放状态、当前页、总页数和缩放比例；
- 翻页范围约束、同一会话重复命令互斥和服务端权威回写；
- 缩放命令互斥和服务端权威回写；
- 退出放映确认及确认期间的槽位、会话和身份复验；
- 屏幕切换、播放会话变化、身份变化和页面销毁后的迟到响应、错误提示和忙碌状态清理。

`PlayerConsole.vue` 从 1437 行降至 1401 行。模板、样式、按钮位置、API、缩放步进和用户提示保持不变；后续剩余主要边界为显示设备电源控制。

## 3. 防回归契约

新增 9 项可执行测试，覆盖：

1. 文档状态始终来自当前权威播放通道；
2. 翻页按 1 到总页数约束，并只提交服务端返回的状态；
3. 同一会话请求在途时拒绝重复翻页；
4. 切换屏幕后，旧翻页响应不能覆盖新屏幕，新屏幕操作不被旧请求阻塞；
5. 更换播放会话后，旧缩放响应不能覆盖新会话；
6. 缺少播放会话时在本地拒绝命令；
7. 退出确认期间会话变化时不终止新会话；
8. 页面销毁后抑制迟到成功、失败和提示；
9. 结构门禁禁止文档 API 和编排函数回流到页面组件。
