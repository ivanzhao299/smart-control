> 日期：2026-09-21

> 结论：音频页首批无状态投影和数值换算已拆出并发布生产；设备轮询、矩阵与音量命令、播放控制和配置持久化仍由页面编排，后续继续按用例和组件边界收敛。

## 1. 变更动机

`AudioPage.vue` 同时负责背景音乐播放、EKX 场景、音频矩阵、输入增益、输出音量、立体声联动和配置编辑。立体声卡片与推子展示所需的纯计算夹在设备命令和轮询状态之间，使展示规则难以独立验证，也增加后续拆组件时误改现场控制时序的风险。

本批次建立 `frontend/src/features/audio-view-model.ts`，集中负责：

- 按“·左/·右”命名约定建立对称立体声关系；
- 只隐藏完整配对的右声道，保留未配对通道；
- 生成通道显示名称、地址、左右行和联动主键；
- EKX 百分比与 dB 的双向换算及真实增益文本；
- 竖向推子坐标换算、边界钳制和 5% 步进；
- 播放时长格式和可见输出总览。

页面继续负责所有带副作用的行为。模板、样式、API 地址、设备命令参数、合并发送机制和下发顺序均未改变。页面从 2177 行降至 2148 行；它仍是超大模块，本批只证明第一层纯模型边界，不把整个音频页拆分项标记完成。

## 2. 数据与发布边界

- 无数据库迁移，不读取或写入生产配置，不发送设备命令。
- 发布范围分类为 `frontendCode=true`、`backendCode=false`、`highRisk=false`、`scope=frontend`。
- 后端发布验证被跳过；生产日志明确执行“frontend code only”，不构建或重启后端。
- 数据库只读检查返回 `MIGRATIONS_CURRENT`；无需备份或迁移隔离环境。
- 前端旁路构建后原子切换，保留上一代 45 个 PWA 兼容资源。

## 3. 自动验证

新增 9 项回归，覆盖：

1. 完整立体声配对与未配对右声道保留；
2. 显示名称、地址、左右行和联动主键；
3. EKX 增益曲线端点、折点、单调性和往返；
4. 前端增益换算在 -10% 至 110% 每一个整数点均与后端协议函数一致；
5. 未知增益显示“—”，不伪造设备读数；
6. 推子坐标钳制、5% 步进和零高度边界；
7. 总览按投影后的通道计数，只用未静音通道计算平均音量；
8. 播放时长维持既有展示格式；
9. 页面必须消费共享模型，禁止同批纯逻辑回流。
