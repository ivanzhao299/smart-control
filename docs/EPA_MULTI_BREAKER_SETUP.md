# ePa 智能断路器多路接入说明

## 支持的接法

### 共用一台 RTU-TCP 转换器

- 多台断路器并接在同一条 RS485 A/B 总线上。
- 每台断路器必须使用不同的 `slaveId`，范围为 `1..255`。
- 每条 `hardware_units` 记录使用相同的 `ip`、`port`，使用各自的 `slaveId`。
- 系统按 `ip:port` 复用通信队列，逐条发送 Modbus RTU 帧。

出厂地址通常为 `255 (0xFF)`。系统后台“硬件清单”已提供“修改485地址”：它会先检查同一总线地址冲突，再写寄存器 `0x0103`，用新地址验读，最后保存硬件台账；台账保存失败会尝试把设备改回原地址。

设置新地址时，应由具备资质的电气人员一次只接入一台尚未改址的断路器；否则多台出厂地址相同的设备会同时响应。

## 建议地址规划

| 地址 | 用途               | 状态                             |
| ---: | ------------------ | -------------------------------- |
|    1 | LED 大屏现有总闸   | 在维护窗口把现有 `255` 改为 `1`  |
|    2 | 同总线新增回路 1   | 预留                             |
|    3 | 同总线新增回路 2   | 预留                             |
| 4–31 | 后续同协议回路     | 预留                             |
|  255 | 新设备临时入网地址 | 只用于逐台改址，不作长期运行地址 |

推荐施工顺序：

1. 先保持总线上只有现有 LED 总闸，把地址 `255 → 1`，确认 LED 控制和计量正常。
2. 新设备每次只接一台，先以 `255` 登记并确认可读，再依次改为 `2`、`3`……。
3. 改址成功后再接下一台；A/B 极性、115200/8N1 和终端电阻按现场总线规范检查。
4. 每台设备单独建立硬件记录和电源回路，切勿让两条记录共用同一个 `ip:port:slaveId`。

### 每台使用独立转换器

- 每台断路器配置不同的 `ip` 或 `port`。
- 各自位于独立 RS485 总线时，可以继续使用出厂地址 `255`。

## 数据配置

每台物理断路器建立一条硬件记录：

```json
{
  "code": "BREAKER-EXAMPLE-1",
  "category": "power-breaker",
  "ip": "192.168.50.21",
  "addressing": "{\"port\":502,\"slaveId\":1}",
  "enabled": true
}
```

每路电源回路的 `gatewayCode` 必须精确填写对应的硬件 `code`；断路器是一台设备对应一路回路，`relayChannel` 留空。

## 协议口径

- 串口：RS485 两线制，`115200 / 8N1`。
- 读保持寄存器：功能码 `0x03`。
- 开关状态：寄存器 `0x0027` 低字节，`0=分闸`、`1=合闸`、`2=上锁`。
- 电机操作：功能码 `0x06`，寄存器 `0x0101`；`1=合闸`、`2=分闸`、`3=上锁`、`4=解锁`。
- 修改设备地址：功能码 `0x06`，寄存器 `0x0103`。
- CRC16 低字节在前。

## 上线门禁

1. 核对每台设备的名称、用途、安装位置、额定电压和额定电流。
2. 核对实际接法、转换器 IP/端口和每台断路器地址。
3. 同一 `ip:port` 下的 `slaveId` 不得重复；系统会在下发前拒绝重复配置。
4. 先逐台读取状态和计量值，再进行单路合分闸测试。
5. 确认每次操作只影响目标回路，再开放前台控制。

## 4G 设备

户外路灯和水泵的 4G 开关不接这条 485 总线，也不使用从机地址。它们通过独立 MQTT 通道接入，详见 [ePa 4G/MQTT 接入运行手册](./EPA_4G_MQTT_RUNBOOK.md)。
