## 1. 本批目标

`AudioPage.vue` 仍直接维护输入源目录、设备真实增益/静音回读和连续推子写入。设备整表读取约需 4.6 秒，旧请求晚返回时可以覆盖新请求；账号或服务器切换后，旧环境中已经排队的增益值也没有统一失效边界。输入目录同时使用进程级 SWR 缓存，切换服务器后存在短暂显示上一服务器名称的风险。

本批新增 `useAudioInputs.ts`，将输入通道完整用例收敛到单一组合式边界。页面只负责调用和渲染，`AudioPage.vue` 从 1673 行降至 1608 行。

## 2. 收敛后的责任边界

组合式用例统一负责：

- 输入目录直读，控制页不复用可能属于上一服务器的 SWR 缓存；
- 设备真实增益和静音状态映射，读取失败时不编造设备数值；
- 目录与设备慢读取均采用“当前身份下最新请求获胜”，迟到响应不能覆盖当前页面；
- 推子继续使用与后端 EKX 协议一致的分段增益曲线，百分比和 dB 显示行为保持；
- 每个输入通道串行写入，只保留在途请求后面的最新值；不同通道可独立发送；
- 新推子值会使同通道旧结果失效；旧失败不会丢弃仍然有效的最终待发值；
- 身份、服务器或页面作用域变化后，旧排队指令不再发送，迟到响应和错误不再提示；
- 真正切换服务器时立即清除旧输入目录和设备读数，再从新服务器加载权威状态。

本批没有修改 EKX-808 指令、接口路径、数据库实体或表结构，也没有改变矩阵、输出音量、静音、场景或背景音乐逻辑。

## 3. 防回归契约

新增 6 项行为与结构测试，并更新共享命令队列结构契约，覆盖：

1. 并发目录和设备回读只允许最新请求提交；
2. 设备增益、静音、未知值、百分比和 dB 文本保持原有映射；
3. 同一通道连续拖动只发送首值和最终值，不同通道独立执行；
4. 身份变化后重新读取权威状态，丢弃旧排队写入并抑制旧错误；
5. 服务器变化先清空旧环境，再提交新服务器直读结果；
6. 页面作用域销毁后禁止迟到目录、设备读数和错误进入页面；
7. 结构门禁禁止输入目录、真值回读和输入增益写入回流 `AudioPage.vue`。

测试使用注入服务和 Vue 内存状态，不连接生产数据库、音频矩阵或现场设备。
