# 音源矩阵读写生命周期

更新：2026-09-17。本地候选实现，未发布到 GK9000。

## 责任边界

`features/useAudioMatrix.ts` 负责真实矩阵读取、交叉点写入合并、状态过期标记和定时对账。`AudioPage` 只负责界面绑定，并沿既有 `useActivePolling` 在进入/返回页面时启动、离开时停止。

该模块不负责背景音乐播放列表、预设场景、输入增益、输出推子、静音或音频配置改名；不改变后端身份验证、设备协议、端口接线或数据库权威源。请求继续由既有 `audioService` 发起，不在页面拼接地址。

## 行为契约

- 交叉点点击立即更新显示，同一点在途时只保留最新目标，不逐次增加整表读取。不同交叉点分别排空，后端原有设备串行机制不变。
- 成功写入后，整批等待 1.2 秒统一读设备；可见且激活的页面保留原有 8 秒状态轮询。正在写入或等待对账时不额外轮询，后台标签不发定时查询。
- 查询同时绑定页面激活周期、账号/服务器身份、查询序号和写入序号。点击前启动的旧读取，即使在写入完成后返回，也不能覆盖新点击；旧错误不能把后来的成功读标为离线。
- 每次成功命令保存该批最近一次确认。后续命令失败时回到最近一次确认，并读取设备对账；不能回滚成整批开始前已经过期的状态。读失败保留最近显示并明确标记过期，不伪造“全部断开”。
- 离开页面取消轮询/延迟对账、丢弃尚未下发的合并目标。在途请求可能已经到达服务器，不能宣称撤销；它完成后不再安排查询或发送下一条命令。
- 返回页面重新读取设备。离开前的响应不能启动第二条轮询链，也不能清除返回后新操作的在途标记。
- 换账号/服务器清空矩阵显示和旧队列；旧身份的结果、错误和后续命令全部作废。销毁时取消定时任务并退订身份事件。

## 验收

- 13 项模块/集成契约测试覆盖上述竞态、失败、隐藏标签、生命周期与账号隔离；全前端累计 157 项通过。
- 真实 Chrome 打开完整构建页面，矩阵查询/命令由测试运输层模拟，其余登录和配置来自全新临时 SQLite + Mock 后端。验证连续点击、第二条命令失败后最近确认回退、切到首页后不补发命令/查询、返回缓存页面读设备状态。
- 浏览器按实际配置的行列数验证矩阵，不把 DSP 的 8×8 物理上限误作所有安装必须展示 64 个按钮。新库当前配置产生 56 个交叉点。
- 既有媒体上传/权限、三路投放/重连、管理员控制、运营数据冲突和缓存旅程通过。

此证据不代表真实 EKX-808 的听感、端口接线或现场响应时延验收。预设长按、推子和输入增益等剩余生命周期仍在阶段 2 范围内，不能因本模块独立而宣称整个音频页面已收敛。
