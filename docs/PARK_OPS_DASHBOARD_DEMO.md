# 金湖科创产业园智慧运营总览 Demo

## 目标
- LED 设计基准：3612×1462。
- 作为 Smart Control 的内置 `webpage` 投放源，在 LED 屏幕和投影仪页面的“输入源”卡片中直接选择。
- 9 月 10 日接待前先用模拟数据演示，后续逐项替换真实 API。

## 页面
1. 综合态势：园区概况、产业结构、经济运行、空间态势、人车、视频、消防事件。
2. 企业经营：入驻企业、行业、人员、产值、招商载体。
3. 安全消防：设备在线、巡检、隐患闭环、安全趋势。
4. 人车管理：当前在园、访客、车辆、停车、门岗事件。
5. 视频监控：4 个重点摄像头槽位 + 在线状态。

## 操作
- LED 屏幕和投影仪页面：在“输入源”中点击“园区运营大屏”即可投放到当前屏幕；正在播放时卡片会保持选中状态。
- 前后端错峰更新时，卡片会自动兼容旧版后端的媒体投放接口，不依赖现场数据库中的数字 ID。
- 页面右下角：上一页 / 自动轮播 / 下一页。
- 键盘：左方向键上一页，右方向键或空格下一页。
- 自动轮播周期：12 秒。
- `system-branding.welcomeGuest` 非空时，顶部欢迎语自动替换为该称谓。

## 摄像头接口预留
当前槽位：`CAM-001`、`CAM-018`、`CAM-043`、`CAM-067`。
拿到真实 API 后优先确认：
- 播放协议：HLS(m3u8) / WebRTC / RTSP 转码 / 厂商 JS SDK。
- 鉴权方式：token、签名 URL、Cookie 或内网免鉴权。
- URL 有效期及是否需要后端代理。
- 浏览器/CORS 限制。

若源为 RTSP，不直接在 Chromium 中播放；由现有服务或新增轻量网关转为 HLS/WebRTC 后嵌入。

## Demo 数据说明
页面所有产值、税收、企业数、人车数、摄像头数均以“演示数据”显式标识，不作为园区正式统计口径。

综合态势页使用园区鸟瞰图作为空间态势底图；当前叠加点位和业务数据仍为演示内容，正式接入时需按真实楼栋及系统数据重新校准。

## 上线前门禁
- 本地/现场 kiosk 以 3612×1462 实屏验证，无裁切、无滚动条。
- Smart Control 媒体库能看到“金湖科创产业园·智慧运营总览(DEMO)”。
- LED 屏幕和投影仪页面的“输入源”均能看到“园区运营大屏”卡片，并可分别投放到对应屏幕。
- 手机端通过输入源卡片推送后切换成功，返回原欢迎页/视频正常。
- 5 页按钮和自动轮播正常。
- 摄像头 API 接入后连续播放 30 分钟无黑屏/鉴权过期。
