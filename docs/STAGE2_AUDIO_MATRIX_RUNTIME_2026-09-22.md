## 1. 本批目标

`AudioPage.vue` 仍直接维护矩阵真实状态、8 秒轮询、交叉点乐观切换、失败回滚、写后复读和页面生命周期。快速连点、服务器切换或页面停用时，页面内分散的请求版本和计时器难以证明旧请求不会进入当前状态。

本批新增 `useAudioMatrix.ts`，将矩阵运行时完整用例收敛到单一组合式边界，并加强既有矩阵命令控制器的失效检查。页面只负责调用和渲染，`AudioPage.vue` 从 1608 行降至 1495 行。

## 2. 收敛后的责任边界

组合式用例统一负责：

- 矩阵真实状态、离线、过期和错误状态；
- 设备读取采用“当前身份下最新请求获胜”，迟到结果不能覆盖当前页面；
- 交叉点立即乐观显示，同一交叉点串行发送并只保留最新等待值；
- 不同交叉点可独立发送，不互相阻塞；
- 失败时回滚到最后一次设备确认值，并立即权威复读；一批写入结束后再进行一次延迟对账；
- 页面激活时每 8 秒轮询，页面隐藏、写入或对账期间跳过无效轮询；
- 身份、服务器和页面作用域变化会使旧读取、旧排队写入、旧提示和旧计时器失效；
- 真正切换服务器时立即清除上一服务器的矩阵状态和确认值，再读取新服务器。

矩阵命令控制器新增逐条命令有效性快照：已经失效的等待命令不会发送，旧命令的成功或失败也不会更新确认状态、回滚界面或产生错误提示。

本批没有修改 EKX-808 指令、接口路径、数据库实体或表结构，也没有改变输入增益、输出音量、场景和背景音乐逻辑。

## 3. 防回归契约

新增 7 项行为测试，并更新矩阵控制器结构契约，覆盖：

1. 并发矩阵回读只允许当前身份下的最新请求提交；
2. 快速连点只发送首值和最终有效值，失败回滚到最后一次设备确认值；
3. 不同交叉点独立发送，同一交叉点保持串行；
4. 身份变化后丢弃旧排队写入、迟到读取和旧错误；
5. 服务器变化立即清空旧环境，并只提交新服务器状态；
6. 页面隐藏、停用和恢复时正确停止或恢复轮询；
7. 写入失败立即复读，一批写入结束后只保留一次延迟对账；
8. 结构门禁禁止矩阵真值、写入、对账和轮询职责回流 `AudioPage.vue`。

测试使用注入服务、计时器和文档可见状态，不连接生产数据库、音频矩阵或现场设备。
