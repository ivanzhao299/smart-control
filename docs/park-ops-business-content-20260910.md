## 页面内编辑

右上角“运营数据”→修改数字/文本→“保存本机草稿”。可导出或导入 JSON。

发布兼容性：页面加载预打包的普通脚本 `ops-content.js`，源代码继续维护在两个 `.mjs` 文件中。构建时自动校验包与源代码一致，避免 PlayerPage 的不透明来源 sandbox 阻止 ES 模块而留下旧数字。没有放宽播放器 sandbox 或静态服务器 CORS。数字编辑和持久保存应在直接打开的大屏页面进行；播放器受限框架只负责展示。

- 数字、公司清单、配套、荣誉、事件占位均可编辑；数字可以标记/取消标记为占位。
- 编辑对话框暂停轮播并隔离键盘事件，空格可正常输入。
- 保存失败保留当前展示并提示导出备份；导入或接口读取先填表，不直接替换展示。
- 不提供生产保存按钮。本地存储不等于后台共享保存，也不会同步到 LED/投影。

## 预留数据接口

数据结构的唯一实现为 `frontend/public/park-ops/ops-data-model.mjs`，导出的 `defaults` 是完整 JSON 示例，`fields` 定义单位和格式，`validate()` 是校验入口。

```text
GET /api/park-ops/metrics  （建议路径，当前后端尚未实现）
Content-Type: application/json
{
  version: 1,
  source: 数据提供者及统计口径（字符串）, updatedAt: ISO日期时间（字符串）,
  placeholderKeys: 仍属占位的 metrics 键名称数组,
  metrics: 所有 fields 定义的指标；值为非负有限数字或 null,
  content: 所有 copyFields 定义的字符串/字符串数组
}
```

响应为完整文档，不能仅返回部分字段；拒绝格式不符、负数、无穷值、超过100的百分比或非法计数。`null` 与 `0` 不等价。当前默认全部有数字，不显示“待接入”。未知键（包括地图配置）不会进入保存内容。接口更新后，把已接入指标从 `placeholderKeys` 移除即可取消占位标记。

编辑器内预留手动 GET 读取测试入口，只允许同源 `/api/` 独立业务路径；禁止管理员、鉴权与布局路径、跨站地址和重定向；8秒超时，失败保留现有值，未配置时不轮询。生产共享写入及其鉴权/冲突控制需后续独立实现，不能复用布局保存接口。

## 本地验收

生产只读配置快照：4个分区、17个楼栋（2026年9月10日本次读取，不是持续同步）。快照留在工作树外，不随代码提交。

预览服务器启动参数：

```sh
OPS_LAYOUT_SNAPSHOT=/absolute/path/to/reviewed-layout-response.json \
OPS_DISPLAY_SOURCE=/absolute/path/to/production-park-ops-3d.js \
OPS_BASELINE_HTML=/absolute/path/to/production-index.html \
node tools/park-ops/preview-server.mjs
```

入口 `http://127.0.0.1:5200/screen/index.html`。不要以 `file://` 打开；ES模块及配置读取需要本地 HTTP 服务。

显示脚本快照用于严格复现生产：生产当前 renderScale=0.82，而远程主分支已有其他任务的 renderScale=1 变更。本次不回退主分支，也不把该显示改动混入业务内容更新；本地服务器仅为验收提供生产脚本快照。后续发布不得直接把整个新工作树覆盖生产大屏。

检查命令：

```sh

PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs node tools/park-ops/browser-test.mjs
```
