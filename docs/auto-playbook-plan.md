# 楼顶大屏自动编排系统 · 完整开发计划

## 一、设计总则

### 1.1 视觉规范（楼顶户外大屏 273×30 点阵）
- **观看距离**：楼顶大屏，远观 30-100 米，字体必须粗、大、高对比
- **配色原则**：背景深色/黑底，文字亮色（白/金/红/蓝），远看不花
- **动画克制**：滚动/淡入为主，不做花哨切换，户外强光下不晃眼
- **安全边距**：上下各留 1 行黑边，左右各留 2 列，不贴边

### 1.2 文案原则
- 每屏不超过 12 字，短句有力，适合远观
- 园区身份：金湖科创产业园 / 金湖科创中心
- 语气：大气、欢迎、招商、科技感，不喊空口号

## 四、播放时间控制（关键）

**不自己定时间表，读电源开关状态：**

1. **数据源**：楼顶大屏电源回路（1f-led / seq-4 / seq-2）的定时开关计划
   - 后端已有电源定时任务（auto-switch），记录了每天几点开、几点关
2. **播放逻辑**：
   - 电源开 → 自动启动轮播（推流到 PVE）
   - 电源关 → 自动停止推流
   - 电源开着但无操作 → 按当前时段模板自动轮播
3. **时段内细分**：
   - 白天（开灯后 - 18:00）：日常宣传 ↔ 招商专题交替（各 25 秒）
   - 傍晚（18:00 后 - 关灯）：欢迎莅临模板
   - 节日当天：节日模板优先，覆盖以上

## 六、开发分期

### P1：后端模板生成引擎（3 天）
- [ ] 后端 service：内置 6 套模板的 bin 生成逻辑（Canvas/Node 端渲染）
- [ ] 节日日历配置表（DB migration）
- [ ] API：`POST /api/led-program/auto/generate?template=daily` 一键生成 bin 入库
- [ ] 生成结果：直接写入 led_programs 表，带类型标签（daily/festival/welcome/invest）

### P2：前端自动编排面板（2 天）
- [ ] LedProgramPage 下方加折叠面板：当前模板状态 + 一键生成按钮
- [ ] 节目库列表：显示类型标签、自动轮播状态
- [ ] 今日排期预览：按节日日历 + 电源时间算出今天播什么

### P3：定时轮播引擎（2 天）
- [ ] 后端定时任务（cron）：
  - 读电源定时计划 → 确定当前是否在播放时段
  - 判断今天是否节日 → 选模板
  - 按时段选对应节目 → 自动推流到 PVE
- [ ] 电源开关联动：开屏自动播，关屏自动停
- [ ] 交替轮播：日常/招商每 25 秒切一个（通过 PVE 循环模式实现）

### P4：后台节日日历配置（1 天）
- [ ] 后台设置页加节日日历表格：可编辑每年节日日期
- [ ] 模板文案可后台微调（不改代码）

## 七、技术要点
- bin 生成全部在后端完成（Node canvas），不依赖前端浏览器
- PVE receiver 不变，还是推 bin 到 192.168.77.10:8080
- 轮播通过 PVE block 模式自动循环，后端只需切换 bin 文件
- 电源状态读后端现有 auto-switch 定时计划，不另建时间表
