## 1. 本批目标

`PlayerConsole.vue` 仍直接维护 LED 和投影显示设备的组合电源回路。目录读取、断电确认和逐路串行下发只校验屏幕与身份，并按数组下标写回设备结果；如果回路分组在请求期间变化，旧响应可能写入错误位置或污染新的页面状态。

本批把完整显示设备电源控制提取到 `usePlayerPowerControls.ts`。目录读取和设备操作同时绑定当前回路分组与身份边界，服务端响应按设备 ID 写回，配置变化、身份变化或页面销毁后旧结果不再进入当前界面。

## 2. 收敛后的责任边界

组合式用例统一负责：

- 按显式回路 code 保序选择，再追加名称规则匹配的时序器功放回路，并按设备 ID 去重；
- 读取权威电源目录和派生全部通电、部分通电、全部断电状态；
- 全部通电时显示断电确认，确认结束后复验当前分组与身份；
- 对共用串口链路保持逐路串行下发，单路失败后继续处理剩余回路；
- 以回路 ID 写回服务端权威结果并汇总部分失败；
- 配置、身份和作用域变化后的迟到目录、设备响应、错误和忙碌状态清理。

`PlayerConsole.vue` 从 1401 行降至 1352 行。模板、样式、按钮位置、回路选择规则、设备 API 和串行下发顺序保持不变。

## 3. 防回归契约

新增 9 项可执行测试，覆盖：

1. 显式 code 顺序、名称规则追加和 ID 去重；
2. 权威目录投影与全部通电判定；
3. 回路配置切换时只有最新目录结果可以提交；
4. 多路上电严格串行，并按回路 ID 写回；
5. 断电确认期间分组变化会取消旧操作；
6. 单路失败不会跳过后续回路，并明确报告部分失败；
7. 身份失效会停止剩余硬件命令并抑制旧提示；
8. 页面销毁后抑制迟到目录并清除可见状态；
9. 结构门禁禁止电源服务和编排函数回流到页面组件。
